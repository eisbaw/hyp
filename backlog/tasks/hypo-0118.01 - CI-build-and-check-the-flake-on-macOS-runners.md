## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Part of HYPO-0118 (GitHub #1, https://github.com/eisbaw/hyp/issues/1). Developers here have no Mac, so CI is the only place the Darwin flake outputs actually get built and tested. The issue proposes running the existing `nix flake check -L` job on ubuntu-latest, macos-15 (ARM64) and macos-15-intel.

Locally, the Darwin outputs can only be evaluated (derivations instantiate), not built.
<!-- SECTION:DESCRIPTION:END -->
